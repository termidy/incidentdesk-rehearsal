## Goal
The response examples of #41, #42 and #43 are pinned by tests, so a renamed or dropped field fails a check.

## Steps
1. Add `tests/api/test_mobile_contract.py`: for each endpoint under `/mobile/v1`, seed data that matches the issue's example, call the endpoint and compare every field of the example.

## Tests
- Every response example is a test: `tests/api/test_mobile_contract.py`, one test per example.
- A renamed or dropped field fails: each test compares the full set of keys with the example.
- The whole suite passes: `pytest -q`.

## Risks
- An example that disagrees with the code: the test pins the example (the contract) and the pull request says so.

## Out of scope
- Application code; the documentation of #44.
